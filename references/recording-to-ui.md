# 录屏包装、截图讲解与辅助交互演示

核心是让观众看见真实产品怎样使用。呈现方式按 **录屏包装 → 截图讲解 → 搭建的界面演示** 选择，不是三个同等优先的风格选项。先分析当前讲解需要连续操作、稳定阅读，还是一个核心交互的快速说明，再处理画质和动效。

## 第一选择：包装实机录屏

默认围绕原录屏剪辑、整理节奏、聚焦目标、添加少量标注和摄影机调度，保留操作位置、实际状态变化和结果。完整界面与局部景别按信息需要交接，不要求每一帧都展示全屏。

先在实际观看尺寸检查可读性，再看操作开始、变化和结束。裁切仅在对象边界完整、放大仍清楚、整个使用区间都能跟随对象时采用。菜单关闭、滚动和窗口重排后，不能让旧矩形继续截取无关区域。不得用放大、阴影和透视掩盖破碎字形或残缺控件，也不要长期叠放原录屏与放大副本。

同时在原始分辨率执行 [源文件四边检查](framing-and-bounds.md)。原录屏左侧已经缺了 Logo 或导航时，必须在选材阶段发现；整张视频完整装入卡片不等于实机界面完整。优先找完整素材或把不需要的缺边区域整体排除，不能遗留半图标，也不能因此直接升级为整片 UI 重建。

能通过合理剪辑、实录加速或聚焦讲清的操作，继续使用录屏。压缩重复打字或等待时保留必要的起始状态、关键动作与真实反馈；若会影响观众对实际耗时的判断，说明已加速或缩短。不得为了节奏切断旁白或重要步骤。

## 第二选择：用真实截图讲清稳定状态

当前重点是阅读提示词、看清设置、解释一处差异或比较结果，连续运动反而干扰时，从正确时间点选取清晰截图。截图也适合在录屏滚动、压缩波动或弹窗干扰下，保留一个确实可读的状态。

选完整窗口或足够理解位置的区域，避免半句文字、半个菜单和无关输入法候选。用于包装讲解的截图默认按 [截图高亮与卡片运动](screenshot-motion.md) 设计明显三维运镜、目标高亮与独立素材动作，读字时收稳；不能只摆一张图再套静态框。不能用冻结画面假装系统仍在输入、生成或实时反馈。截图不会自动修复低清；不要把模糊帧放大后称为清晰重建。

截图讲清后按需要返回实机过程或结果。无需把每段都转成截图卡片，也不固定截图占比或停留秒数。

## 最后选择：为具体价值点或核心交互搭建短段演示

只有当前段落要解释某个明确价值点，或核心交互用录屏/截图表达仍冗长、不清楚时，才搭建必要的界面或交互信息。不能仅因为源片画质一般就把教程整体重做为 UI 动画。

适用例子：录屏输入打字很长，可以用符合真实产品风格的输入窗口，紧凑呈现已核验的输入内容与提交动作，再接回真实响应。若只是需要观众读完提示词，一张清晰截图通常更合适，不必再演一次打字。

先确定演示要让观众理解什么，只搭建这个信息或交互需要的最小对象：输入框、关键选项、引用关系或短反馈。使用可编辑文字、原始图标或矢量组件整理字阶、间距、边框、圆角与材质，保持产品辨识度，不扩展成整套应用复刻。给模糊截图套边框不算搭建。

按实际素材选择两种衔接方式，不做固定模板：

- **实机背景加交互信息**：使用同一段或相邻且状态一致的真实录屏作为底层，适度虚化、压暗或降低对比；前景呈现清楚的输入、选项或价值说明。背景仍能辨认当前操作场景，前景与实机里的对象有位置、名称或动作关联。
- **短暂的独立交互特写**：先建立真实界面上下文，暂时进入必要的精致窗口演示，讲清后立即接回实机操作、反馈或结果。不得连续把多个章节都替换成脱离录屏的搭建界面。

虚化不是默认滤镜。关键操作本来就在录屏中发生且需要观察时，保持它清楚；背景不得在被遮挡期间悄悄跳过关键状态。底层播放时前景应与同一操作阶段对应；需要冻结背景帮助阅读时，选明确状态的截图，不任意循环无关录屏。虚化施加在背景素材层，不施加在会压平三维结构的 world/camera 父层或清晰信息层。

## 原始内容与展示编排的边界

当次录屏、清晰截图和适用的 UI 资产库共同提供依据。沿用已确认的 Logo、图标、色彩、透明度、字体与组件比例；旧设计快照不能覆盖当次实录的功能状态，不修改只读设计源来方便实现。

- 产品内的提示词、模型名、选项、数值和反馈必须核验。不要把 OCR 猜测写成精致但错误的 UI。长内容只展示相关部分时，说明省略或摘要，并区分包装文案与产品原文。
- 可以压缩示意打字与展示节奏，不能改写输入意图、操作顺序、完成状态或产品能力。点击、高亮和指针按同一控件几何定位；反馈仍遵循原材料中的因果。演示时长不代表产品真实响应速度。
- 案例影像与结果继续使用真实素材，不因“界面美化”而重新生成更好的产出。看不清的信息先从已授权材料核对，非必要细节可省略；影响操作或结论的未知信息不能猜测。
- 在现有计划或素材记录中保留来源和时间段，标明录屏、截图或辅助交互演示，以及演示要表达的具体作用。交付说明区分实录与搭建部分，不增加例行确认环节。

## 阅读中心与空间调度

一个主要阅读中心不等于删除实机背景。全局建立位置，特写讲清操作，真实结果承担效果证据；通过清晰度、对比、前后距离和遮挡分出主次，避免两份界面同时争抢注意。字幕独立安排安全区，不把原字幕和输入法候选一起裁进前景窗口，也不叠出两套字幕。

相机、素材和交互分别编排，让不同深度产生有目的的视差。运动完成后给出稳定、正向、可读的落点。3D 服务于真实场景中的关注点与交接，不以更大倾斜、更强模糊或更多搭建组件衡量质量。

## 验收

- 观众能持续辨认这是实机使用教程，知道在哪里操作、发生了什么、结果如何；主线没有变成纯界面演示。
- 呈现选择符合优先级：录屏能讲清则包装录屏，稳定状态优先截图，搭建片段有明确的价值点或核心交互用途，并完成回到实机/结果的交接。
- 没有强行放大的低清块、残缺句子、失效裁切或重复阅读中心。若出现，先重新考虑剪辑与截图，再判断是否确需辅助演示。
- 使用虚化录屏时，前景清晰、背景可定位、两者状态相关；关键动作没有被虚化隐藏，字幕没有被遮挡。
- 搭建组件的样式符合产品，文案、状态与因果可追溯；静态排版、连续交互和最终导出分别检查后，才声明该项目已验证。
