# 原创空间动画与导出

根据内容自行写 HTML/CSS/JS，包内没有场景预设。相机、素材和交互使用 [空间舞台](camera-space.md) 的可编排接口，或当次项目需要的原创实现；保持独立使用，不加载其他 Skill。

## 原生 UI 与混合素材

仅在 [录屏、截图与交互演示](recording-to-ui.md) 所述的具体价值点或核心交互短段中，用 DOM 文字、CSS 布局和适用的 SVG/图标搭建必要状态。默认教程仍以实机录屏为主；可把同段录屏作为适度虚化的背景，前景演示输入、选项或引用关系，再接回真实反馈。背景视频、截图和案例保留来源与时间映射，不内置通用产品模板。

`window.seek` 同时设置重建状态、控件变化和独立的摄影机/素材轨道。点击与高亮从实际 DOM 控件投影获得坐标。重建部分没有逐帧视频可核对时，用原始操作前后状态与因果检查，不把新编排的动效时长声称为产品真实响应速度。

## 确定性契约

- 提供 window.seek(seconds)，每次按绝对时间设置全部轨道；支持任意前后跳转，不能依赖累计状态、系统时间或随机数。
- 暂停 WAAPI/CSS 动画，通过 currentTime 或明确插值驱动。导出器逐帧检查，后续镜头误启动的自动动画也会被拒绝。等待字体、图片与媒体就绪。
- 文件自包含或使用项目内相对资源。导出器阻止网络加载；字体、图片、视频都先冻结到项目中。
- 画布与导出尺寸一致。透明输出时页面与非素材背景必须透明，并留出投影与轨迹范围；world 保持 3D 上下文，HUD 在正向阅读层。导出器不会自动移除作者设置的底色。
- 黑底局部彩光需在 HTML 的独立后景层按绝对时间编排漂移、扩散或呼吸，遵循 style-quality.md；`init` 的纯黑底色不会自动产生光晕。不要用运行中的无限 CSS 动画制造不可复现的背景。
- 按 framing-and-bounds.md 检查源内容四边、图像适配、遮罩及完整运动轨迹。导出器能成功截图，不代表 Logo、图标或文字没有被切掉。
- 指针/高亮依据实际素材内对象的投影，点击、绑定与完成反馈对齐可见状态。

## 视频素材进入三维面板

录屏和案例视频可放入空间面板，不必先变成一张静态截图。使用本地可解码的 MP4/WebM，并明确时间映射：

```html
<video src="media/clip.mp4" data-timeline data-start="1" data-end="5" data-source-in="2" data-speed="1" muted preload="auto" playsinline></video>
```

场景 1–5 秒对应源视频 2–6 秒。data-end 省略时为场景导出终点；源素材必须覆盖有效范围。window.seek 负责面板和相机，以及素材在有效区间外的隐藏/交接；渲染器逐帧暂停、定位并等待视频解码后截图，不播放实时录屏来碰运气抓帧。

HTML 中的视频音轨始终静音，最终声音在剪辑计划中处理。大文件先做保留时间映射的轻量代理，或截取当前镜头范围，降低解码/跳转成本。浏览器不支持的编码先转为当地可解码格式。

## 导出

```sh
node scripts/render_motion.mjs --html /path/project/graphics/scene.html --out /path/project/graphics/scene.mov --duration 6 --width 1920 --height 1080 --fps 30 --transparent
```

MP4 用于完整镜头；带透明度的 ProRes MOV 可以作为 plan.json 的 overlay。可以传 --modules 使用已有 node_modules，传 --browser 指定已有 Chromium，FFmpeg 通过 PATH 或 FFMPEG_BIN 定位。没有相应软件时给出具体缺项，保留工程。

先渲染短段代理，看真实视频帧、相机视差、遮挡与操作文字，再导出正式质量。源码、素材时间映射与最终包装一起交付。

编码先写入本次临时目录，成功后才替换目标文件。失败会保留检查帧，并保住原有成片。
