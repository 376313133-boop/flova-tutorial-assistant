# 以摄影机与交互组织教程

默认把教程看作连续发生的操作与理解过程。围绕材料设计镜头与运动，不按旁白一句换一页，也不把所有内容先做成卡片再依次淡入。

默认采用强空间感三维运镜：相机确实改变位置与观看目标，近远层产生明显的相对视差、尺度和遮挡变化。包装镜头以运镜组织视线，卡片与窗口另有可见动作。静态倾斜、加阴影、统一 scale 或源视频自己在播放，都不能替代这些设计。截图/高亮的具体做法见 [截图高亮与卡片运动](screenshot-motion.md)。

动效以实机展示为基础，依次考虑录屏包装、截图讲解，最后才是具体价值点或核心交互的搭建演示。冗长打字可整理成短段输入演示，再回到实际反馈；不要把持续搬动低清截图当成交互，也不要让搭建 UI 取代实机主线。选择方法见 [录屏、截图与交互演示](recording-to-ui.md)。

## 每段的运动决定

用简短的当次镜头说明记录：从哪里看、要靠近哪个对象、路径如何走、什么动作触发反馈、在哪里稳住、怎样交给下一段。时长由旁白和观察难度决定。

把运动分成四个独立部分：摄影机负责视野、景别、空间路线和注意力接力；素材负责进入、绑定、选中、归档、展开、生成状态和结果；文字/HUD 负责价值、操作标签与短反馈；指针/高亮根据实际对象投影移动，并在接触后出现对应响应。

同一时刻一个主运动，不等于全片弱运动。先让摄影机或当前卡片完成明显动作，再交给高亮与阅读；摄影机快移时，文字和素材不再各自高速飞动。需要看清结果时，相机减速稳定。

同一时刻应有一个主要阅读窗口，同时保留实机场景的可辨识性。全局到特写通过对象位置、轮廓或状态交接；辅助演示期间，原录屏可适度虚化或压暗退后，讲清后恢复真实操作或结果。组件的展开、内部重排和状态变化与相机分开编排；避免每段都重复原录屏后退、矩形副本前移。

## 优先主动设计的动作

- 全局到特写：先建立对象位置，相机以可辨认的前后推进与横移，落到输入框、素材或版本差异。前景与远景有不同运动幅度，保持能识别的界面参照。
- 横移跟随：素材从参考区进入提示词或项目空间，相机追踪同一个对象；投影位置、标签与反馈一起更新。
- 前后层交接：前景是当前操作，中景是结果，远景是全局。用距离、遮挡和焦点接力，避免全部平铺同一层。
- 拉远揭示：从正在编辑的内容退出到多个任务或整体作品组织；相机退后，外围对象逐步进入视野，体现尺度变化。
- 弧线观察：围绕素材/项目对象走出可辨认的空间弧线，展示前后层与遮挡关系，再回到便于读字的方向；不用几乎看不见的摆动交差，也不为炫技绕行。
- 运动匹配转场：通过同一个对象、轮廓、位置、方向或内容关联交接；转场完成后有稳定观察区间。

可推荐少量运镜思路供用户比较，但不规定镜头数量、摆位或时长。每次依材料重新设计。

## 关键帧与速度

关键帧表达预备、加速、运动、减速、落点、停留和交接中的必要部分。不是所有对象只有起点和终点，也不是每个动作都需要弹跳。

镜头轨迹明确相机位置与观看目标；素材另设位置、转角、尺度和状态。用速度对比建立节奏：明显移动之后有停留；微交互有短促反馈，空间揭示有完整减速。

先锁定旁白、点击、状态出现的同步锚点，再填中间关键帧。点击在命中目标后，完成声对齐可见完成变化。多任务按空间、依赖或阅读方向错峰，避免无依据的随机飞入。

## 不通过的表现

连续段落沿用标题加平铺卡片；主要变化只有淡入、飘入或整张画面的轻微缩放；仅加阴影就宣称 3D；所有层随相机同速移动；控件与指针坐标分离；相机反复摇摆、无目的绕行；读字时强视差/大幅旋转；为动态感跳过真实结果。

## 验证

正常播放看注意力接力，慢放与中间帧看插值和遮挡，静帧看排版。检查运动前、中、后与交接，尤其是点击、高亮、绑定、关键文字、完成反馈和结尾。正式导出前执行 [反 PPT 动效自检](quality.md#反-ppt-动效自检)，不能仅凭关键帧数量或技术名词通过。

坐标与实施见 [摄影机与素材空间](camera-space.md)，渲染见 [动画导出](animation.md)。
