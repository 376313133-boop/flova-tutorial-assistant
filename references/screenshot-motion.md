# 截图高亮与卡片运动

用于录屏中的界面截图、局部讲解、设置对比和作为空间面板的素材。优先级仍是录屏包装、截图讲解、最后短段搭建演示。截图是实机的真实状态，不因要做动效就改成全套 UI 复刻。

## 截图不是静态幻灯片

先标出当前讲解目标及它在原图中的位置，决定相机从哪里看、怎样接近目标、在哪里停稳、如何交给下一步。默认把截图放在有纵深的场景中，用明确的摄影机推进、横移或弧线观察组织讲解，而不是更换一张图再淡入一个框。

下面是一种可选的因果编排，不是固定分镜模板：

1. 全局先建立操作位置，前后景关系可辨认。
2. 相机向目标推进并横移，背景产生不同于主体的视差；目标在运动后稳定进入阅读区。
3. 非目标信息适度压暗，轮廓沿目标边缘绘出、局部亮区展开或强调线扫过关键文字；选择一种主要高亮机制。
4. 根据旁白逐项移动注意力，高亮跟随真实目标，标签随后落位；比较内容保持相同观察条件。
5. 留出读字时间，再回收高亮、让当前对象归位，或沿同一对象/方向交接到下一处和实机画面。

动作应在实际播放尺寸、正常速度下明显可见。只给截图持续 1%–2% 微缩放、一个静态矩形框或整张图循环漂浮，不算完成截图讲解的运动设计；这个例子用于识别弱动作，不是设定新的缩放阈值。

## 高亮有动作，也有准确位置

- 轮廓描画、聚光区域展开、关键行渐进强调、对比区域切换、标注线从对象连接到说明，都可承担注意力交接。选用与内容有关的表达，不在同一处同时叠加圈线、脉冲、箭头和发光。
- 高亮建立在真实截图或控件坐标上。优先把描边、蒙版和目标放在同一素材平面，共用变换；放在 HUD 时，按目标四角投影绘制形状，不能用固定屏幕矩形套住倾斜中的目标。
- 换图、裁切、窗口比例或相机状态变化后重算绑定。动效开始、中段和收稳后都检查，高亮不能漂移到无关控件，标注线不能与对象分离。
- 四角投影和高亮绑定之外，还须执行 [源素材与包装边界检查](framing-and-bounds.md)。截图自身已有缺边、高亮只包住半个控件、内部遮罩切字，都不能因相机轨道正确而通过。
- 局部抬升仅用于完整、清晰且确有必要的区域；不为做立体效果强切半句文字、菜单碎片或低清素材。无法干净提取时，让相机接近原图目标并用标注强调，或按呈现优先级重新选帧。
- 高亮是解释层，不把讲解中的圈注伪装成产品原生选中/完成状态。静态截图上的点击示意不能被声称为实机刚刚发生的动作。

## 卡片与窗口必须有独立可见动作

先设计素材自身的轨道，再与相机配合。可选动作包括：从真实位置抽取到前景、沿 Z 轴错层展开、带转角进入并转正落位、内容重排、参考沿路径归入目标、前后卡片交换主次、沿原路径归位。动作围绕当前操作或内容关系选取，不要求每张卡都完成所有动作。

卡片不是进场淡入后始终静置。主要包装卡片要有能指出起点、动作和落点的独立空间变化，或窗口展开、折叠、重排等可见结构变化；仅换文案、高亮颜色、改变透明度、播放片内视频，或只靠相机带着整组卡片一起移动，都不能冒充卡片动作。反过来，只有卡片飞入、相机始终不变，也不能满足默认三维运镜要求。

用前景、中景、背景的真实距离建立明显的尺度差与遮挡，接触阴影和边缘材质辅助说明距离。卡片转动和相机推进分别编排；主动作之后收稳，文字在阅读阶段正向清晰。录屏与截图中的原始像素仍保持真实，不用重绘内容制造更多层。

同一时刻只突出一个主动作。避免所有卡片同速晃动、循环弹跳或同时发光；明显的进入、展开和交接可以与稳定阅读形成速度对比。真实结果播放不需要为了“每秒都动”额外旋转或推拉。

## 从动作关系交接，而不是从页面切换

在相邻镜头之间保留对象身份、目标位置、运动方向或操作因果：相机追随同一素材走向下一步，特写退回可定位的实机窗口，或当前结果接管原有关注点。不能把连续片段都处理成“上一张消失、下一张出现”。

这些规则不规定固定布局、镜头数或时长。先按素材编排，再执行 [反 PPT 动效自检](quality.md#反-ppt-动效自检)。静帧漂亮只证明排版；相机、卡片、高亮及交接都需要连续运动证据。
