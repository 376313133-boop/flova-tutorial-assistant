# 品牌简约·精密（默认）

通过准确字阶、明确比例、克制材质和空间调度建立品牌感。默认是中性黑底与局部虚化彩色光晕动效，不采用暗绿大底。按当次 Flova 素材选择适用的局部光色，背景缓慢变化，实机画面、文字和 Logo 保持清楚与原色；具体做法见 [视觉质量与配色](../style-quality.md)。用户明确指定其他颜色时执行其选择。

让录屏、案例和关键操作成为主视觉。UI 作为可接近、可展开的空间平面；前后距离、遮挡、透视和相机路线建立层次，状态光只在交互发生时响应。

按 [录屏、截图与交互演示](../recording-to-ui.md) 优先包装实机录屏，其次用清晰截图，只为具体价值点或核心交互搭建短段精致窗口。可在同段实机背景适度虚化的基础上呈现清楚的交互信息；演示完成后回到真实过程，不把整片变成 UI 搭建展示。

字体与版面精确，但不限制为某个固定网格。文字在阅读落点稳定；相机在段落之间主动调度，关键操作前后有清楚景别变化。

默认采用强空间感三维运镜：明确的前后推进、横移或弧线，以及不同深度的可见视差。卡片另有抽取、错层、展开或旋转落位等独立动作，截图高亮随目标推进。精密简约不等于弱动作；只有静态排版、统一缩放和淡入不能通过 [反 PPT 自检](../quality.md#反-ppt-动效自检)。

失控信号：整片暗绿/青色偏色、满屏浓蓝光、全屏玻璃或发光边框；只有静态纯色却宣称完成背景光效；每页都是标题加卡片；只做整体微缩放；为了“高级”缩小真实操作到看不清，或让半个 Logo/导航从素材边缘露出来。
