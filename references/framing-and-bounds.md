# 源素材与包装边界完整性

边界检查先于运镜验收。必须分开判断源素材是否完整、包装是否新增裁切。卡片四角在画面里，不代表卡片里的 Logo、导航和文字没有缺失；技术解码、时长或黑帧检查通过也不证明边界合格。

## 先检查源文件四边

在原始分辨率查看实际使用片段的左、右、上、下边缘，关注 Logo 的首尾、导航图标、第一列文字、菜单边框、输入框与提交按钮。对每种界面布局至少检查代表帧；窗口移动、缩放、重排或弹出菜单后重新检查，不能用开场一帧代表全片。

源画面本来就有半个 Logo 或导航图标时，标为源素材缺边，不能通过 `contain`、增加内边距或套新外框把它认证为完整窗口。几何投影只能确认现有像素是否又被裁掉，不能恢复原文件之外的内容。

处理顺序：

1. 优先从已授权素材找同一操作或状态的完整录屏、清晰帧或截图。
2. 当前讲解不需要缺失区域时，选择完整的内容窗口/控件组，把有缺陷的侧栏等区域整体排除；裁切线落在空隙或明确的容器边界，不留下半字、半图标或一条残缺侧栏。把它作为内容特写，不冒充完整应用视图。
3. 只有在已符合短段价值点/核心交互演示条件时，才搭建必要辅助信息，并遵循 [呈现优先级](recording-to-ui.md)。不能仅因缺边就把整片改为 UI 重建，更不能猜画缺失的控件或状态。
4. 若缺失部分是完成当前教学必需的证据，记录缺口；有其他可做内容时先推进。只有确实无法替代时才向用户索取更完整素材，不悄悄补造。

## 每个镜头明确观看范围

- **整窗展示**：窗口主体、应出现的 Logo/导航/控件完整，四角与必要内边距在画布内。装饰性投影或柔光可以自然延出画幅，不得把关键内容的裁断当作投影溢出。
- **内容特写**：允许不展示整套应用，但要保留当前目标、所需上下文和完整文字/控件。不要在画面边缘留下无用途的半截品牌、图标或菜单；有意裁切也需选择干净边界。
- **入场/退出过程**：对象可从画幅外进入或离开，关键阅读状态必须完整；不能让文字在观众应阅读的阶段仍被遮罩切着。不要拿有意退出解释中途意外缺边。

产品自身的滚动视口可按原样呈现，但应能辨认它的滚动边界；不把包装新增的误裁解释为原生滚动。用户明确要求的局部放大同样需要目标完整，不要求为了保住无关外框而把关键文字缩得过小。

## 从内到外排查裁切来源

| 层级 | 检查内容 | 修正方向 |
|---|---|---|
| 源像素 | 原视频/截图边缘是否已经缺字、缺图标 | 换完整片段或选取干净的内容范围，不猜补 |
| 媒体适配 | 源宽高比、`object-fit`、`cover`、裁切偏移、像素到设计坐标换算 | UI 默认等比容纳；核对内容区域，避免超出盒子后被裁掉或拉伸 |
| 容器与遮罩 | `overflow`、`clip-path`、圆角、内边距、子层尺寸和遮罩参考坐标 | 外壳和内容边界分别检查；给可读内容留真实内边距，勿用 `overflow:hidden` 掩盖布局错位 |
| 三维投影 | 相机位置/target/焦距，卡片位姿和尺度，四角与关键目标的投影 | 调整相机距离、卡片位置/尺寸和路线；不只检查中心点 |
| 画幅与遮挡 | 最终裁切框、字幕/HUD 安全区、前景卡片遮住的内容 | 重排主次与空间；必须完整的 Logo、句子、按钮不得被另一层压住 |

使用透明 Logo 或 SVG 时，只能排除真实透明留白，不得裁到可见字标或符号。背景光晕、阴影的视觉外延与可读 UI 内容边界分开判断。

## 检查整个轨迹，不只起点终点

用实际渲染尺寸和同一套几何变换检查三维平面的四角，以及源像素中当前必须看清的内容矩形。关键目标与截图的边框、内边距、等比留边、裁切偏移都要纳入换算。能用同平面绑定的目标，优先共享变换；HUD 中的目标边缘需按四角投影，不能只以一个中心点和固定宽高推断。

包内 `anchorStage`/`anchor` 可投影面板上指定位置；`elementAnchor*` 读取的是轴对齐外接框，只能用明确的零尺寸定位点取得对应点位，不能直接拿控件外接框冒充透视四角。API 的 `visible:true` 不检查画布越界、祖先裁切或前景遮挡，不能单独作为通过条件；具体坐标换算见 [摄影机与素材空间](camera-space.md#坐标与镜头)。

逐帧或按足够密集的运动采样检查：进入、加速/减速、最大透视、最大放大、回弹极值、落位和交接。发现越界后加密对应时间段，直至明确边界。几何检查需要覆盖目标穿越近裁面、嵌套容器裁切和前景遮挡；只检查整个元素的轴对齐外框不能替代这些判断。

整体窗展示时，把内容最靠近四边的时刻作为重点检查帧。特写时，检查当前目标及裁切线附近是否出现残字或残图标。保留按输出尺度选择的安全余量，不能在数学上刚好贴边就通过；余量随阴影、圆角、运动和观看尺寸调整，不套单一像素数。

不要通过去掉最终画幅裁切、给 world 加 `overflow:visible` 或弱化所有运镜来掩盖问题。修正构图和轨迹后重新检查，保留默认的三维空间表达。

## 验收证据与失败处理

在现有审片记录中留下镜头/时间段、观看范围、必须完整的目标、问题层级、源边缘对照、输出四边细节、中间帧和修正结果。对来源不完整、必读内容被切、边缘残留半图标/半字的情况判为未通过，修正后再导出。

原始分辨率检查负责发现缺字与残边，实际观看尺寸检查负责判断是否清楚；二者不能互相替代。截图或渲染工具的自动通过只说明其检查范围，不能据此宣布没有语义缺边。没有实际检查的镜头保持待验证，不用勾选清单代替图像证据。
