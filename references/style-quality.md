# 品牌简约视觉与配色

默认品牌简约、精密，采用中性黑色包装底与局部虚化彩光动效，重点是视觉秩序、镜头调度与交互感。默认不用暗绿、墨绿或大面积青绿色底。黑底是当前默认方向，不规定版面、镜头顺序或卡片模板；用户明确指定其他方向时优先执行。

默认运动是明显的强空间感三维运镜，卡片/窗口有独立且可见的动作。简约与克制约束信息、材质和装饰，不把摄影机运动缩成微漂移，也不把截图变成平面幻灯片。优先做出明确深度、相对视差、对象动作和稳定阅读之间的节奏。

## 形成当次设计

先从当前材料判断：哪个是主要证据、哪里需要看清操作、素材自身什么颜色最有价值、哪些地方需要空间关系。确定主视觉、字体层级、颜色职责、材质和动效强弱，再安排构图。

- 标题承担核心价值；提示词、操作与实际反馈承担过程；案例承担结果。避免一屏几段解释文案同时争抢注意。
- 录屏、素材与文字的占比按当前动作改变。完整界面可以进入特写，素材可以离开列表走到前景，镜头可以拉远揭示群体。
- 简洁来自去掉无作用内容，同时保留有目的的视差、层次和交互。大面积空白与静态对称排卡本身不能证明设计质量。

## 黑底与局部虚化彩光

底色以中性黑为主。`#050506` 可作项目起点，表面用中性深灰或透明黑，文字用清楚的白与中性灰；这些是本 Skill 的制作默认值，不是未经核验的 Flova 官方 token。不要从 Logo 的绿色或某一帧的绿色光斑推导出整片暗绿底，也不要给原录屏、作品影像和 Logo 做统一绿/青调色。

彩色只在背景局部形成柔化的光团、宽软光带或散射光。光色参照当次 Flova 实录/授权素材里的蓝紫、暖红橙等关系，选择少量适用颜色，不必同时出现。原 Logo 的颜色保持原样。背景大部分仍应读成黑色，不能让多层叠色把整个画面变成绿色、紫色或蓝色雾幕。

露出包装背景的镜头，光晕应有独立、缓慢的漂移、扩散或明暗呼吸轨道；不要把一张静态径向渐变称为已完成炫光动效。运动按绝对时间驱动，可在关键阅读时减弱或停稳，长段循环不得跳变。它不能抢过主运镜，也不把所有光斑同时闪烁。产品状态反馈与环境光分别编排，不用背景呼吸伪装按钮响应。

光晕放在实机和清晰信息之后，避免光团中心压在正文、字幕、关键控件上。给模糊外延留空间，检查裁切边缘不能出现硬矩形或突然截断的光带。虚化只施加于独立背景光层，不施加在整个 3D world/camera 上。全屏实机或结果画面不必强行叠光；透明包装也不能擅自填黑。

每次明确底色、内容表面、文字、强调与状态色的职责。最终检查合成后的背景，而非只看 CSS 底色：确认黑色占主体、无暗绿整体偏色，光晕柔和且确有变化，压缩后没有明显色带、波纹或闪烁。必要时使用轻微确定性抖动和足够码率。源素材与设计快照不提供这些新动效的真实时长或缓动参数。

## 视觉质量

检查字形、断行、行距、字距、边界和阅读顺序。大字有稳定落点；辅助文字足够少且实际播放尺寸可读。素材裁切、画幅与景别服务当前信息，但必须通过 [源素材与包装边界检查](framing-and-bounds.md)。外层圆角卡片完整，不能抵消内部 Logo、侧栏或文字已经缺边的问题。

材质影响运动：纸片有抬起和接触，精密面板有清楚的距离与停稳，卡通可以预备和形变，流程沿轴和路径推进。材质与光效不应让所有元素同时发光、漂浮或摇晃。

实机展示是主体，优先包装录屏、其次选择清晰截图。仅为具体价值点或核心交互短段搭建精致 UI，必要时在同段录屏虚化背景上叠加；不能把真实数值、结果、控件含义和操作改写成虚构功能。搭建部分保持产品风格，案例影像保持真实。具体选择与边界见 [录屏、截图与交互演示](recording-to-ui.md)。

先确认活动窗口的完整性和阅读中心，再评价 3D、光效与质感。全局录屏和放大副本不能长期同时抢占前景；裁断的字、残缺控件和低清截图不会因加边框或透视而变得合格。

默认品牌简约·精密。纸感拼贴、手绘白板、卡通、等距流程仅作备用表达，可局部使用；具体构图自由设计，不要求整片切换身份。
